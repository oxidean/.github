# Contributing to Oxidean

A repository's own `CONTRIBUTING.md` always takes precedence — this file is the
org-wide default for repos that don't define one. For the forge itself, see
[`oxidean/oxidean` → CONTRIBUTING.md](/oxidean/oxidean/blob/main/CONTRIBUTING.md).

Expectations that apply across the org:

- Read the repository README and docs before opening a PR.
- Keep pull requests small and focused; include tests for behavior changes.
- Never commit secrets: `.env` files, tokens, private keys. Use example files.
- Extend existing patterns and dependencies instead of adding new frameworks.
- By contributing, you agree your contributions are licensed under the
  repository's license (MIT unless the repo says otherwise).
